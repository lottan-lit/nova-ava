# Nova AVA (simulação completa)

Abra index.html no navegador. Login simulado: qualquer dado funciona.

## Páginas
Painel · Disciplinas · Página da disciplina (aulas, materiais, atividades) · Atividades (entrega simulada) · Notas · Calendário · Conta do aluno

## Estrutura
- index.html      estrutura e telas base
- css/style.css   tokens Soft UI, componentes e responsivo
- js/data.js      dados de exemplo (cursos, atividades, notas)
- js/store.js     estado, persistência (localStorage) e regras
- js/views.js     HTML de cada página
- js/main.js      rotas, ações, modal e tema

O progresso, as entregas e o perfil ficam salvos no navegador. Em Conta, use Reiniciar simulação para voltar ao início.
